# Cin-Track-V2
CinéTrack est une application web dynamique permettant de gérer et d'interagir avec un catalogue de films et de séries.

Le projet se divise en deux parties principales : un espace d'administration pour la gestion complète du catalogue (opérations CRUD) et une interface utilisateur enrichie permettant de consulter les œuvres, de lire/ajouter des commentaires et d'attribuer des notes.

# Fonctionnalités principales
Panel d'Administration : Ajout, modification, suppression et affichage des films et séries.

Interactions Utilisateurs : Système de commentaires et notation (1 à 5 étoiles) intégrés dans une fenêtre modale détaillée.

Synchronisation API : Communication fluide avec une API REST (MockAPI) pour la gestion des données en temps réel.

# Stack Technique
Front-end : HTML5, Tailwind CSS

Logique : JavaScript (ES6+, Modules, Fetch, Async/Await)

Back-end / BDD : MockAPI (API REST)
